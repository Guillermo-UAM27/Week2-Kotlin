# 🎯 Kotlin: Fundamentos de Programación

Este repositorio contiene una serie de implementaciones prácticas desarrolladas en **Kotlin**, centradas en aplicar los pilares de la Programación Orientada a Objetos (POO) en escenarios del mundo real. 

El objetivo es demostrar un código limpio, seguro y fácil de mantener.

---

## 🏗️ Pilares Implementados

### 🧬 Herencia y Jerarquía
Diseñamos modelos basados en una **Clase Madre (Superclase)** que define el comportamiento base, permitiendo que las **Clases Hijas (Subclases)** hereden y especialicen sus funcionalidades.
* **Uso de `open`:** Para habilitar la extensión de clases y métodos.
* **Uso de `override`:** Para personalizar comportamientos en las subclases.

### 🛡️ Encapsulamiento
Protegemos la integridad de los datos mediante el uso de modificadores de visibilidad (`private`). Esto asegura que los atributos sensibles solo sean modificados a través de métodos controlados, evitando estados inconsistentes en la aplicación.

### 🧩 Abstracción e Interfaces
Implementamos contratos de comportamiento que permiten tratar diferentes objetos de manera uniforme, facilitando el escalamiento del software.

---

## 💻 Estructura del Proyecto

El código está organizado para mostrar casos de uso prácticos como:
* **Gestión de Usuarios:** Jerarquías de personas y roles específicos.
* **Sistemas Financieros:** Modelado de cuentas bancarias con datos protegidos.
* **Logística y Transporte:** Uso de interfaces para controlar diferentes tipos de flota.
* **Sistemas Académicos:** Organización de registros para bibliotecas y universidades.
